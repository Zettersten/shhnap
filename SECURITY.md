# Security reports

Please report security vulnerabilities through [GitHub private vulnerability reporting](https://github.com/Zettersten/shhnap/security/advisories/new) rather than a public issue. Include the Shnapp version, Windows version, and enough steps to reproduce the problem. Do not include private capture contents unless they are necessary to explain the issue.

For ordinary bugs and feature ideas, use the [issue forms](https://github.com/Zettersten/shhnap/issues/new/choose).
